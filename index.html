ArcadeAi for Clubs

ArcadeAi is a Hack Club program where you/your members build games and get rewarded. Run it as a workshop at your next meeting no experience needed, and it works for complete beginners. Clubs are welcome from anywhere in the world!

Running a workshop

Host an ArcadeAi workshop at your club meeting. Members will build their own game using a AI (As per the guide), host it on GitHub Pages, and submit it. Each approved submission earns them rewards. You can use our workshop guide to run the session.

Using AI?

Why Are We Using AI?

Games can take weeks to build from scratch. And AI is great tool to learn if used in the right way. So for ArcadeAi, we want to encourage participants to use AI to build the first version of their game, then improve it with their own ideas and creativity. AI helps you learn in this and makes the process a bit faster so you can focus on experimenting, creating, and making something uniquely yours (aka your own first game).

AI Helps you Build the first version.
You build the final game.

AI Helps With

  • Creating a prototype
  • Writing code
  • Fixing bugs
  • Adding features
  • Explaining concepts

You Focus On

  • Coming up with ideas
  • Testing your game
  • Improving the design
  • Making it fun
  • Adding personality
AI can generate code.
It can't generate your creativity.

Learn everything you need to know about ArcadeAi, submissions, rewards, workshops, and project requirements.

Rules & Guidelines

Requirements

  • You must be between 13 and 18 years old.
  • You must not be banned from Hackatime.
  • You must spend at least 1 hour working on your project.
  • Your project must be your own work.

Individual Submission Requirements

  • You must be a member of the Hack Club Slack.
  • Your identity must be verified using Hack Club Auth.
  • You must track your time using Hackatime.
  • You must submit a working project.
